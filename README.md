# Logseq Monokai Theme

A [Logseq](https://logseq.com) CSS theme inspired by the [Monokai Pro](https://monokai.pro/) color palette.
Supports Logseq v2 styling systems.

## Installation

### As a Plugin
1. Open Logseq and go to **Settings > Plugins**.
2. Go to the **Marketplace** tab.
3. Search for "Monokai Theme" and click Install.
4. Select the theme in **Settings > General > Theme**.

### As a Custom CSS snippet
Add the following to your `custom.css` file:
```css
@import url('https://cdn.jsdelivr.net/gh/adambullmer/logseq-theme-monokai@main/custom.css');
```
